# 🎲 Mesa Aberta

*Histórias que aproximam...*

## 📖 Sobre o projeto

A **Mesa Aberta** é uma ONG fictícia que busca promover a inclusão social, a criatividade e a colaboração por meio do RPG de mesa.

Este site foi desenvolvido como projeto acadêmico da disciplina de Fundamentos da Web e Desenvolvimento Front-end.

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo das páginas.
- **CSS3:** estilização, Flexbox e responsividade.
- **JavaScript:** validação de formulário e interatividade.

## 🌐 Páginas do site

- **Início:** apresentação da ONG e suas iniciativas.
- **Sobre:** história, missão, visão e valores.
- **Projetos:** Primeiro Dado, Histórias em Cena e Vozes da Mesa.
- **Contato:** formulário para participação, voluntariado e mensagens.

## ⚙️ Funcionalidades JavaScript

1. **Formulário interativo:** validação de informações e exibição de mensagens de retorno, com envio apenas simulado.
2. **Orientações da ONG:** botão interativo que permite mostrar e ocultar informações sobre participação e voluntariado, utilizando JavaScript para atualizar o conteúdo da página.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
